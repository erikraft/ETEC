# 🏫 ETEC de Peruíbe - Repositório Acadêmico

Este é um repositório **privado** dedicado ao armazenamento, organização e desenvolvimento de todos os trabalhos, atividades e matérias do Ensino Médio integrado ao Ensino Técnico na **ETEC de Peruíbe**. 

O objetivo deste espaço é centralizar os conteúdos das aulas e manter o histórico de projetos práticos desenvolvidos ao longo do curso.

---

## 👥 Desenvolvimento em Dupla
Este repositório e o seu arquivo `README.md` são mantidos e gerenciados de forma colaborativa por uma dupla de estudantes.

> 🔒 **Acesso Restrito:** Por ser um projeto privado, o acesso ao código-fonte e aos materiais é controlado. O desenvolvedor **[@erikraft](https://github.com/erikraft)** é o responsável por adicionar novos membros e colaboradores convidados à organização do repositório.

---

## 🛠️ Organização e Recursos do GitHub

Para manter o fluxo de trabalho acadêmico organizado, utilizamos as seguintes ferramentas nativas do ecossistema do repositório:

*   💬 **[Discussions](https://github.com/erikraft/ETEC/discussions):** Espaço para debater ideias, tirar dúvidas sobre as matérias e planejar como os trabalhos serão feitos.
*   🌿 **[Pull Requests](https://github.com/erikraft/ETEC/pulls):** Utilizado para revisar as contribuições e códigos de cada integrante da dupla antes de juntar as alterações na branch principal.
*   📌 **[Issues](https://github.com/erikraft/ETEC/issues):** Registro de tarefas pendentes, bugs em códigos de projetos técnicos e prazos de entrega de trabalhos escolares.
*   🤖 **[Actions](https://github.com/erikraft/ETEC/actions):** Automações personalizadas configuradas para rodar testes básicos ou validar a estrutura do projeto a cada atualização.
*   📖 **[Wiki](https://github.com/erikraft/ETEC/wiki):** Documentação detalhada das disciplinas, anotações de conceitos complexos e guias de estudo rápidos.
*   📊 **[Projects](https://github.com/erikraft/ETEC/projects):** Nosso quadro de organização visual (Estilo Kanban) para acompanhar o status de cada trabalho (*A Fazer*, *Em Progresso*, *Concluído*).

---

## 📂 Estrutura de Trabalhos
O repositório armazena entregas divididas por componentes curriculares:
*   📝 **Trabalhos Individuais:** Códigos de fixação, listas de exercícios e pesquisas teóricas individuais.
*   🤝 **Trabalhos em Dupla:** Projetos integradores e atividades práticas desenvolvidas em conjunto.
